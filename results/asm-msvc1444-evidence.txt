==============================================================================

## bench::ScalarSum::sum
   mangled: ?sum@ScalarSum@bench@@SAHPEBEH@Z

  THE LOAD-BEARING ONE. This is the plain scalar loop
        for (int i = 0; i < n; ++i) total += s[i];
    which is the same source C# runs. MSVC turns it into a 256-bit AVX2 reduction
    ($LL4@sum: vpmovzxbd / vpaddd), then a horizontal reduction (vphaddd,
    vextracti128) and a scalar tail ($LL18@sum). RyuJIT leaves this loop scalar,
    because .NET has no auto-vectorizer. That difference is the same-source FIX gap.
    Note the MSVC source annotation directly above $LL4@sum: '; 89 : for (int i = 0;
    i < n; ++i) total += s[i];'. That is the mapping, from the compiler itself.

  span: main.cod lines 57369-57465 (97 lines, verbatim)
